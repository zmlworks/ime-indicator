# IME インジケーター (ImeIndicator) v1.1

*Small resident Windows app that shows the Japanese IME mode as a colored box next to the text caret; written in 100% x64 assembly (NASM).*

文字を入力する位置（**テキストカーソル＝キャレット**、点滅している縦棒）のすぐ右下に、
いまの **日本語入力（IME）の状態** を小さな四角で表示する常駐アプリです。
「今どっちのモードだっけ？」と画面右下のタスクバーを見に行く必要がなくなります。

v1.1 から、表示位置はマウスカーソルではなく **キャレットの横だけ** になりました。
キャレットが見つからないとき（文字入力欄にフォーカスがないときなど）は表示されません。

- Windows 11 / 10 (64 ビット) 用。Intel / AMD どちらの CPU でも動きます。
- 100% x64 アセンブリ (NASM) 製。C ランタイム不要、exe 単体（約 40 KB）で動作します。
- インストール不要・管理者権限不要。レジストリにも何も書き込みません。
- ネットワーク通信なし。キー入力の記録（キーロガー的な動作）やグローバルフックは一切使っていません。

## 表示の意味

| 表示 | 色 | 意味 |
|:---:|:---|:---|
| **あ** | 赤橙 | IME オン：ひらがな |
| **カ** | 赤紫 | IME オン：全角カタカナ |
| **ｱ** | 黄色（文字は濃い茶色） | IME オン：半角カタカナ |
| **Ａ** | 青緑 | IME オン：全角英数 |
| **A** | 紫 | IME オフ（半角英数） |
| **?** | 濃い灰色 | 状態を取得できない（管理者として実行中のアプリなど。下の「制限事項」参照） |

表示は少し半透明で、クリックはすべて下のウィンドウに素通りします（邪魔になりません）。
キャレットの右下に表示し、画面（作業領域）の下端に近いときはキャレットの上側に回り込みます。

### 表示されないとき

次の場合はインジケーターを表示しません（故障ではありません）。

- 前面のアプリでキャレットが見つからないとき（文字入力欄にフォーカスがない、ボタンやリストを選択中 など）
- デスクトップやタスクバーが選択されているとき、本アプリのメニューを開いているとき
- 前面のアプリが **全画面表示**（ゲーム、動画の全画面、ブラウザーの F11 など）のとき

## 使い方

1. `ImeIndicator.zip` を展開し、`ImeIndicator.exe` を好きなフォルダー（例: `C:\Tools\ImeIndicator\`）に置きます。
2. `ImeIndicator.exe` をダブルクリックで起動します。メモ帳などで文字入力欄をクリックし、
   キャレットの右下に「あ」や「A」が表示されれば成功です。
3. 通知領域（タスクバー右下、隠れている場合は「^」の中）に **赤い「あ」のアイコン** が出ます。

二重に起動しようとすると「既に起動しています」と表示され、2 つ目は起動しません。

### 終了するには

通知領域の「あ」アイコンを **右クリック → 「終了」**。

（アイコンが見つからない場合は、タスクマネージャーの「詳細」タブで `ImeIndicator.exe` を終了しても構いません。）

### Windows 起動時に自動で起動するには（スタートアップ登録）

1. `Win + R` を押し、`shell:startup` と入力して Enter。スタートアップフォルダーが開きます。
2. `ImeIndicator.exe` を **右クリックしたままドラッグ** してそのフォルダーに持って行き、
   「ショートカットをここに作成」を選びます（exe 本体ではなくショートカットを置くのがおすすめです）。
3. 次回のサインインから自動で起動します。やめるときはそのショートカットを削除するだけです。

## 初回起動時の警告について（SmartScreen）

この exe は **コード署名されていない** ため、初回起動時に
「Windows によって PC が保護されました」という青い画面が出ることがあります。
その場合は **「詳細情報」→「実行」** をクリックしてください。

また、インターネットからダウンロードした zip を展開した場合は、exe を右クリック →「プロパティ」→
下部の **「許可する」（ブロックの解除）** にチェック → OK としておくと、警告が出にくくなります。

心配な場合は、同梱のソースコード (`ime_indicator.asm`) を確認し、自分でビルドすることもできます（下記）。

## 制限事項・注意

- **キャレット位置が取得できないアプリでは表示されません。** 例:
  - 一部のターミナル（Windows Terminal、一部の SSH クライアントなど）
  - ゲームや、独自にキャレットを描画しているアプリ（一部のエディター、独自 UI のアプリ）
  - リモートデスクトップ / 仮想マシンの画面の中
  - アクセシビリティ情報を公開していない一部の UWP / ストアアプリ
  - Chrome / Edge / Electron 製アプリなどは通常表示されますが、ページや入力欄の作りによっては
    位置がずれたり表示されないことがあります。
- **管理者として実行しているアプリ**（タスクマネージャー、管理者のコマンドプロンプトなど）では、
  Windows のセキュリティ機能（UIPI）により IME 状態を取得できず **「?」** と表示されるか、
  キャレット位置が取得できずに表示されないことがあります。
  どうしても必要なら本アプリも「管理者として実行」すれば取得できますが、通常はおすすめしません。
- 一部のアプリ（UWP、ターミナル、独自の入力処理をするアプリ）では、IME 状態の表示が実際と合わないことがあります。
  これは Windows の IME 状態取得 API（`WM_IME_CONTROL`）の仕組み上の制限です。
- 表示されるのは **前面（アクティブ）ウィンドウ** のキャレットと IME 状態です。
- キャレット位置は 0.05 秒ごと、IME 状態は 0.1 秒ごとに確認しているため、表示の追従・切り替えにわずかな遅れがあります。
- 応答しなくなっているアプリに対してはキャレット位置の問い合わせを行わず、問い合わせが 0.3 秒以上かかる場合は
  打ち切るので、本アプリが固まることはありません（その間は表示位置が更新されません）。
- 対応しているのは日本語 IME（Microsoft IME、Google 日本語入力、ATOK など、標準の IME 状態を公開しているもの）です。
- 複数モニター・モニターごとの拡大率（DPI）に対応しています。高 DPI 非対応の古いアプリでも位置を補正します。
- CPU 使用率はほぼ 0% です（位置や状態が変わったときだけ移動・再描画します）。

## 仕組み（技術メモ）

- 50 ms ごとのタイマーで、前面ウィンドウのスレッドのキャレット位置を次の順に探します。
  1. `GetGUIThreadInfo` の `hwndCaret` / `rcCaret` → `ClientToScreen`（従来の Win32 アプリ、旧メモ帳など）。
     対象ウィンドウの DPI コンテキストで取得し、`LogicalToPhysicalPointForPerMonitorDPI` で物理座標に変換します。
  2. 見つからなければ MSAA: `AccessibleObjectFromWindow(フォーカスウィンドウ, OBJID_CARET)` →
     `IAccessible::accLocation`（Chrome / Edge / Electron、Office、新しいメモ帳、多くの WPF / UWP アプリ）。
     幅・高さが 0 や (0,0) の結果は「キャレットなし」とみなします。
  - UWP / WinUI アプリ（設定、電卓、ストアアプリ等）は前面ウィンドウが ApplicationFrameHost の
    `ApplicationFrameWindow` なので、子の `Windows.UI.Core.CoreWindow`（アプリ本体のスレッド）を対象にして
    キャレット位置と IME 状態を取得します。
  - UI Automation（TextPattern）による取得は、複雑さと不具合のリスクに見合わないため実装していません。
- キャレットが前面ウィンドウの外にある、どのモニターにも無い、などの不自然な位置は無視します。
- 100 ms ごとのタイマーで、前面ウィンドウ → `GetGUIThreadInfo` でフォーカスのあるウィンドウ →
  `ImmGetDefaultIMEWnd` → `SendMessageTimeoutW(WM_IME_CONTROL, IMC_GETOPENSTATUS / IMC_GETCONVERSIONMODE)`
  （`SMTO_ABORTIFHUNG`、タイムアウト 50 ms）で IME 状態を取得し、変化したときだけ再描画します。
- ウィンドウは `WS_EX_LAYERED | WS_EX_TRANSPARENT | WS_EX_TOOLWINDOW | WS_EX_TOPMOST | WS_EX_NOACTIVATE`
  （半透明・クリック透過・タスクバーに出ない・最前面・フォーカスを奪わない）。
- フォントは Yu Gothic UI（無ければ Meiryo UI → メイリオ → MS UI Gothic）。
- Per-Monitor DPI Aware V2（マニフェスト + `SetProcessDpiAwarenessContext`）。
- エクスプローラーが再起動しても通知領域アイコンは自動で復活します（`TaskbarCreated`）。

### 対応状況のまとめ

- 表示される: 従来の Win32 アプリ（旧メモ帳・ワードパッド等）、Chrome / Edge / Electron（VS Code、Slack 等）、Firefox、
  Office、新しいメモ帳、多くの WPF / WinForms アプリ、OBJID_CARET を公開している UWP / WinUI アプリ。
- 表示されない・不正確: Windows Terminal・一部ターミナル、ゲーム、独自描画エディター（キャレットを OS に公開しない）、
  RDP / VM 内、**管理者として実行中のアプリ**（UIPI によりメッセージ・MSAA が遮断。本アプリを管理者で起動すれば回避可。
  `uiAccess=true` による回避はコード署名と Program Files への配置が必要なため採用していません）。
  TSF のみ対応のアプリでは IME 状態がずれる場合があります。

## 自分でビルドする場合

Linux (Debian / Ubuntu) または WSL で:

```sh
sudo apt install nasm binutils-mingw-w64-x86-64 mingw-w64-x86-64-dev zip python3
./build.sh        # ImeIndicator.exe を作成（PE ヘッダーと x64 アンワインド情報の自己チェック付き）
./build.sh zip    # さらに ImeIndicator.zip を作成
```

表示サイズ、キャレットからの距離（`CARET_DX` / `CARET_DY`）、透明度、更新間隔、色などは `ime_indicator.asm` 冒頭の「Tunables」と
`state_table` を書き換えて再ビルドすれば変更できます。

同梱ファイル:

| ファイル | 内容 |
|:--|:--|
| `ImeIndicator.exe` | 本体 |
| `ime_indicator.asm` | ソースコード（コメント付き） |
| `build.sh` | ビルドスクリプト |
| `res/` | アイコン・マニフェスト・バージョン情報（`make_icon.py` はアイコン生成用） |
| `tools/verify_pe.py` | ビルド後の自己チェック用スクリプト |
